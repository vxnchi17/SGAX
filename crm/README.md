# SGAX CRM — авторизация, роли, админка, выплаты

Живая система: Node.js-сервер + база `data/db.json`. Без внешних зависимостей (`npm install` не нужен).

**Запуск:**
```bash
cd SGAX/crm && node server.js      # → http://localhost:8080
```


---

## 📐 Калькулятор пакетов внутри CRM

Встроен калькулятор v6: **«Сделки» → «+ Собрать пакет»** — открывается мастер на 6 шагов, полноэкранный.

```
1. Клиент        название, что рекламируем, ниша, бюджет, дата
2. Площадки      список пакета → нажать на площадку → 5 блоков:
                 ① что это за площадка   ② аудитория (+ «охват 30% от подписчиков»)
                 ③ условия владельца     ④ допродажи (7 опций с процентами)
                 ⑤ наша ставка (общая / своя для этой площадки)
3. Наш процент   карточки 15% эксклюзив / 35% стандарт + слайдер 5–50
4. Услуги        таблица + библиотека готовых (8 услуг)
5. Расходы       прочие, реферал %, округление (100/500/1000)
6. Итог          цена клиента, разбор по площадкам, 6 проверок, CSV, печать
```

**Считать умеет ровно то же, что калькулятор v6** — математика продублирована на сервере и на клиенте, сверено до рубля:

| Пример | 15% | 35% |
|---|---|---|
| 3 Discord (1500+@everyone+pin / 1800+@here / 1200) + креатив 6 000 | владельцам 6 870 · клиент **14 083** · нам **7 213** · маржа 51,2% | клиент **16 569** · нам **9 699** · маржа 58,5% |

Своя ставка на отдельной площадке, реферал, расходы и округление учитываются.

**Что даёт связка с базой:**
- площадки подтягиваются из «Площадок» в один клик — цена, охват, ниша уже заполнены;
- сделка сохраняется со всеми площадками и расчётом;
- кнопка **«Скачать медиаплан CSV»** — готовая таблица для клиента (наш доход в неё не попадает, если скачивает менеджер);
- кнопка **«Печать»** — PDF через печать браузера;
- права: менеджер видит и правит только свои сделки, чужие получают `403`.

## Демо-доступы

| Логин | Пароль | Роль | Что может |
|---|---|---|---|
| `faraday` | `sgax2026` | 👑 **Founder** | всё: учётки, выплаты, настройки, код дня, журнал |
| `head` | `head2026` | 🎖️ **Руководитель** | код дня, заявки на выплаты, контроль своей ветки |
| `maks` | `maks2026` | 🧑‍💼 **Менеджер** | свои сделки, свои выплаты |
| `lera` | `lera2026` | ⭐ **Старший менеджер** | то же + пометка старшинства |

Вход в два шага: **логин + пароль → сменный код дня (6 цифр)**. Основатель входит без кода — чтобы не оказаться запертым снаружи.
Код виден на странице «Код дня» и в «Обзоре». Демо-код на сегодня: смотри на экране после входа основателем.

## Роли и деньги

```
👑 Founder        прибыль = всё, что осталось после выплат
   └── 🎖️ Руководитель   % с прибыли своей ветки + доля (40%) от бонусов менеджеров
          ├── 🧑‍💼 Менеджер      % от бонусного пула + оклад
          └── ⭐ Старший менеджер  то же, что менеджер
```

Формула бонуса (настраивается в админке):
```
бонусный пул сделки = чистая прибыль сделки × пул %
бонус менеджера    = пул × ставка менеджера %      + оклад
бонус руководителя = (пул команды × ставка рук. %) + (бонусы менеджеров × 40%)
```
По умолчанию: пул 15%, менеджер 15% от пула, руководитель 5% с прибыли ветки + 40% от бонусов своих людей.

Принцип закрепления: **кто нашёл клиента — тот и менеджер сделки.** Ветку (кто к кому прикреплён) создаёт только основатель.

## Безопасность (что реально сделано)

- пароли — **scrypt + соль**, в базе нет открытых паролей;
- сессия — **HttpOnly cookie**, из JavaScript её не достать, срок 12 ч (настраивается);
- **второй фактор**: сменный код дня, 6 цифр, умирает в 00:00, выдаёт лид/основатель;
- код **не отдаётся** тому, кто не имеет права его выдавать (менеджер видит только «код выдан/не выдан»);
- 5 неверных попыток → **блокировка на 15 минут**;
- 20 попыток входа с одного IP за 5 минут → стоп на 5 минут;
- учётку может создать **только основатель**, регистрация по приглашению по умолчанию **выключена**;
- блокировка/разблокировка/сброс пароля — только основатель;
- каждый вход, ошибка, блокировка, изменение — в **журнале действий**;
- при создании учётки пароль временный, при первом входе система требует сменить.

## Контроль сотрудников

Система сама следит и оповещает основателя (страница «Обзор» + «Контроль», автообновление 30 сек):

- кто онлайн (был за последние 15 минут);
- кто не заходил 2 дня (жёлтый) / 5 дней (красный);
- у кого ноль сделок;
- «работал сегодня» / «простаивает» / «заблокирован»;
- полоса активности 0–100.

Порог «дней без входа» настраивается.

---

## Автоматические заявки на выплаты

Включено по умолчанию. Каждый день система проверяет: если сегодня 5-е число и 10:00 UTC — **сама формирует заявку** за прошлый месяц: считает бонус каждого, оклад, долю руководителя, остаток основателю. Заявка падает в «Выплаты» со статусом «на утверждении» — основатель жмёт одну кнопку.

Кнопка «⚡ Сформировать заявку» есть и вручную (за текущий или прошлый месяц).

## Правила, которые зашиты в код

1. Учётки создаёт **только основатель** (админка → «Команда»), роли: основатель / руководитель / менеджер / старший менеджер.
2. Руководитель видит **только свою ветку**, менеджер — **только себя**.
3. Утверждать выплаты может только основатель.
4. Менеджер не может повысить себе роль или посмотреть чужие сделки.
5. Пакеты площадок (3/5/10 одной ниши) собираются в «Сделках» из базы площадок; цена клиента считается по модели «сумма владельцам / (1 − ставка)».
