# Автотесты SGAX CRM

Прогоняют интерфейс в эмуляторе браузера: вход, все экраны, мастер пакета, права ролей.

## Запуск

Первый терминал — сервер:
```bash
cd ../crm && node server.js
```

Второй терминал — тесты:
```bash
cd tests
npm install
node test-ui.js      # вход → мастер пакета → создание сделки (19 шагов)
node test-all.js     # все экраны + права ролей
```

Упало — в выводе видно, на каком шаге. Другой адрес сервера: `SGAX_URL=http://host:port node test-ui.js`
