# Как запустить SGAX CRM

Система работает как небольшой сервер на твоём компьютере. Ничего ставить из интернета не нужно — только Node.js.

---

## 1. Поставить Node.js (один раз)

**Windows / macOS:** скачай с [nodejs.org](https://nodejs.org) — большая кнопка **LTS**. Установи как обычную программу, «Далее-Далее».

**Проверить, что встало:** открой терминал (Windows: `Win+R` → `cmd` → Enter; macOS: `Terminal`) и напиши:

```bash
node -v
```

Должно ответить что-то вроде `v20.20.2`. Если пишет «не найдено» — перезагрузи компьютер и попробуй снова.

---

## 2. Скачать проект

**Вариант А — через ZIP (проще):**
1. Открой [github.com/vxnchi17/SGAX](https://github.com/vxnchi17/SGAX)
2. Зелёная кнопка **Code** → **Download ZIP**
3. Распакуй куда угодно, например на рабочий стол. Появится папка `SGAX-main`

**Вариант Б — через git (если он есть):**

```bash
git clone https://github.com/vxnchi17/SGAX.git
```

---

## 3. Запустить

Открой терминал **в папке проекта**. Проще всего:

- **Windows:** зайди в папку `SGAX-main`, в адресной строке проводника набери `cmd` и нажми Enter — терминал откроется уже в этой папке.
- **macOS:** зайди в папку, правой кнопкой по папке → «Новая вкладка в терминале».

Дальше две команды:

```bash
cd crm
node server.js
```

В терминале появится:

```
bootstrap: создан основатель faraday
bootstrap: сменный код на сегодня выдан автоматически
SGAX CRM on http://0.0.0.0:8080
```

**Это значит, что работает.** Терминал не закрывай — пока он открыт, работает сервер. Закроешь — система выключится (данные сохранятся).

---

## 4. Открыть в браузере

Перейди на 👉 **http://localhost:8080**

Экран входа спросит логин и пароль.

| Логин | Пароль | Кто это |
|---|---|---|
| `faraday` | `sgax2026` | 👑 Основатель — полный доступ |
| `head` | `head2026` | 🎖️ Руководитель |
| `maks` | `maks2026` | 🧑‍💼 Менеджер |
| `lera` | `lera2026` | ⭐ Старший менеджер |

⚠️ **Первый вход** — `faraday` / `sgax2026` (только он входит без кода дня).
Потом сразу зайди в **Профиль → Сменить пароль** и поставь свой.

---

## 5. Что делать внутри

### Собрать пакет и посчитать цену

1. Меню слева → **Сделки**
2. Кнопка **«+ Собрать пакет»**
3. Шаг 1: впиши клиента, выбери нишу
4. Шаг 2: **«+ Из базы площадок»** (если база пустая — **«+ Вручную»**), нажми на строку площадки, впиши цену владельца, отметь допродажи
5. Шаг 3: выбери **15%** или **35%**
6. Шаги 4–5: услуги и расходы, если нужно
7. Шаг 6: нажми **«Создать сделку»**

На шаге 6 есть **«Скачать медиаплан CSV»** — готовый файл для клиента (открывается в Excel).

### Завести площадку в базу

Меню → **Площадки** → **«+ Площадка»**: название, тип, ниша, подписчики, охват, цена.

Когда в одной нише наберётся 3 площадки — пакет по ней можно продавать.

### Выдать код дня сотрудникам

Меню → **Код дня** → **«⚡ Выдать код»**. Появится 6 цифр — отправь их в рабочую беседу.

Без этого кода никто не войдёт, даже со верным паролем. Это второй фактор.

### Создать учётку сотруднику

Меню → **Команда** → **«+ Создать учётку»**: имя, логин, роль, руководитель, оклад.

Пароль система сгенерирует сама — передай его сотруднику, при первом входе он обязан сменить.

### Посмотреть, кто работает, а кто нет

Меню → **Контроль**. Обновляется само каждые 30 секунд: кто онлайн, кто не заходил 2 дня (жёлтым) / 5 дней (красным), у кого нет сделок.

### Выплаты

Меню → **Выплаты**. Система сама считает бонусы по закрытым сделкам. Кнопка **«⚡ Сформировать заявку»** — создаёт заявку за месяц. Дальше **«Утвердить»**.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| `node: команда не найдена` | Node.js не установлен или не перезагрузился компьютер |
| `EADDRINUSE` / порт 8080 занят | Закрой другой терминал с сервером, или запусти на другом порту: `PORT=8081 node server.js` (Windows: `set PORT=8081 && node server.js`) |
| Браузер пишет «не удаётся открыть сайт» | Сервер не запущен — терминал закрылся или в нём ошибка. Смотри текст в терминале |
| Забыл пароль основателя | Удали файл `crm/data/db.json`, запусти заново — база создастся с нуля, пароль снова `sgax2026` |
| Закрыл терминал — всё пропало? | Данные не пропали, они в `crm/data/db.json`. Запусти сервер снова |
| Не открывается шаг 2 в мастере | Обнови страницу `Ctrl+F5` |
| Нужен доступ с телефона или другого компьютера | Пока сервер работает на твоём компьютере — доступен только он. Для доступа извне нужен сервер в интернете (VPS) — это отдельная настройка |

## Где лежат данные

```
crm/data/db.json
```

Там всё: пользователи, площадки, сделки, выплаты, коды, журнал. Файл один — его легко скопировать как резервную копию.

**Не выкладывай его в интернет** — внутри хэши паролей. В репозиторий GitHub он специально не попадает (в `.gitignore`).

## Следующий шаг: доступ из интернета

Сейчас система работает на твоём компьютере. Чтобы менеджеры заходили со своих — нужен **VPS** (сервер за 300–500 ₽/мес) и домен. Тогда:

1. копируешь папку `crm` на сервер
2. запускаешь `node server.js` через `pm2` (чтобы не падал)
3. ставишь `nginx` + бесплатный HTTPS от Let's Encrypt
4. меняешь пароль основателя и включаешь обязательный код дня

Это делается за один вечер. Скажи — напишу пошаговую инструкцию под конкретный VPS.
